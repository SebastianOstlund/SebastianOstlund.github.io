# Portfolio Website

A simple static portfolio website.

## Important Files

- `index.html` – Main page layout and UI.
- `style.css` – Site styling.
- `projects.js` – Portfolio data source.

## Data Structures

### window.PROJECTS

Array of project objects used to generate the portfolio section.

### window.SLIDES

Array of slide objects used to generate the slideshow.

## Development Guidelines

- Keep the site dependency-free.
- Maintain compatibility with modern desktop and mobile browsers.
- Project data should be added through `window.PROJECTS`.
- Slideshow data should be added through `window.SLIDES`.
